A LITTLE NOTE BEFORE YOU GO

좋은 여행은
정확한 정보에서 시작해요.

01

사실과 추천을 구분해요

실제 검색은 카카오 로컬의 장소 정보입니다. 가족·개인 적합성, 맛, 편안함은 별도 확인이 필요합니다. 예시 모드는 가상 업체를 포함합니다.

02

조회 시각과 영업 확인일은 달라요

검색 결과 조회만으로 현재 영업을 확인했다고 표시하지 않습니다. 숙박 가격은 날짜·인원별로 달라지며 테스트 환경 가격은 실제 판매 가격이 아닙니다.

03

사진과 사람을 존중해요

이미지는 직접 만든 일러스트이며 현장 사진이 아닙니다. 실제 사진은 이용 조건과 개인정보를 확인한 뒤 추가합니다. 날씨는 Open-Meteo의 모델 추정값입니다.
